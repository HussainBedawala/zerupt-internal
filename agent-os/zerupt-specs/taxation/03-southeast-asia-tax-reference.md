## Singapore — Inland Revenue Authority of Singapore (IRAS)

| Field | Value |
|-------|-------|
| Tax type | GST |
| Standard rate | 9% |
| Zero-rated | Exports, international services |
| Exempt | Sale/lease of residential property, financial services |

## Malaysia — Royal Malaysian Customs Department (RMCD)

| Field | Value |
|-------|-------|
| Tax type | **SST** (Sales Tax + Service Tax — NOT VAT) |
| Sales Tax | 5% or 10% (depending on goods) |
| Service Tax | 6% or 8% (depending on service type) |
| Inclusive/Exclusive | Exclusive |
| Registration threshold | Sales: MYR 500,000; Service: MYR 500,000 |
| Filing frequency | Bimonthly (sales), bimonthly (service) |
| E-invoicing | **MyInvois — mandatory phased rollout from Aug 2024** |

### Sales Tax Rates
| Rate | Applies to |
|------|-----------|
| 5% | Essential items — basic food, construction materials, fruit juices, PCs, phones, watches |
| 10% | Most other manufactured/imported goods |
| Exempt | Petroleum products (separate regime), certain raw materials |

### Service Tax Rates
| Rate | Applies to |
|------|-----------|
| 6% | F&B, telecommunications, logistics, parking, rental/leasing (reduced from 8% in Jan 2026) |
| 8% | Most other taxable services |

### Key Difference from VAT
- **No input tax credit** — SST is single-stage, not multi-stage like VAT
- Tax is levied once (at manufacturer/import level for sales tax, at service provider level for service tax)
- **For Zerupt: must model as separate tax type, not VAT**

### 2026 Changes
- Rental/leasing service tax reduced from 8% → 6% (effective Jan 1, 2026)
- MSME exemption threshold for rental/leasing increased from MYR 1M → MYR 1.5M

### Sources
- [ClearTax — SST Malaysia 2026](https://www.cleartax.com/my/en/sst-in-malaysia)
- [BDO — SST updates Jan 2026](https://www.bdo.my/en-gb/insights/tax/sales-and-service-tax-sst/sales-tax-and-service-tax-sst-jan-2026)
- [MySST Portal](https://mysst.customs.gov.my/About)

## Indonesia — Directorate General of Taxes (DJP)

| Field | Value |
|-------|-------|
| Tax type | PPN (Pajak Pertambahan Nilai / VAT) |
| Standard rate | 11% (most goods/services) |
| Luxury rate | 12% (luxury goods only) |
| Zero-rated | Exports |
| Exempt | Basic necessities, healthcare, education, public transport |
| Inclusive/Exclusive | Exclusive |
| Registration threshold | IDR 4,800,000,000 |
| Filing frequency | Monthly |
| E-invoicing | **e-Faktur — mandatory for all PKP (taxable entrepreneurs)** |

### Two-Tier System (effective Jan 1, 2025)
- **11%**: Standard rate for most taxable goods/services (using 11/12 taxable base formula)
- **12%**: Only for luxury goods — high-end vehicles, luxury residential, certain imports
- The original plan to raise all goods to 12% was narrowed to luxury items only

## Thailand — Revenue Department

| Field | Value |
|-------|-------|
| Tax type | VAT |
| Standard rate | **7%** (temporarily reduced from statutory 10%) |
| Statutory rate | 10% |
| Temporary extension | 7% extended until **Sep 30, 2026** (Royal Decree No. 799) |
| Zero-rated | Exports |
| Exempt | Basic agricultural products, healthcare, education, domestic transport |
| Inclusive/Exclusive | Exclusive |
| Registration threshold | THB 1,800,000 |
| Filing frequency | Monthly (by 15th of following month) |
| E-invoicing | e-Tax Invoice — voluntary for most businesses |

### Critical Note
- The 7% rate has been continuously extended since 1997
- Current extension expires **Sep 30, 2026** — may revert to 10% or be extended again
- **For Zerupt: model as date-effective rate — 7% until Sep 30, 2026, 10% after (with override if extended)**

## Vietnam — General Department of Taxation (GDT)

| Field | Value |
|-------|-------|
| Tax type | VAT |
| Standard rate | 10% |
| Temporary reduced rate | **8%** (2% reduction extended to Dec 31, 2026) |
| Reduced rate | 5% (essential goods) |
| Zero-rated | Exports |
| Exempt | Healthcare, education, financial services, insurance |
| Inclusive/Exclusive | Exclusive |
| Registration threshold | Varies by industry |
| Filing frequency | Monthly (large) or quarterly (small) |
| E-invoicing | **Mandatory — all businesses since Jul 2022** |

### Temporary 8% Rate (Resolution No. 204/2025/QH15)
- Applies to most goods and services at the standard 10% tier
- **Excluded from reduction** (remain at 10%): finance, banking, securities, insurance, real estate, telecom
- Extended from Jul 1, 2025 to **Dec 31, 2026**
- New additions to 8% scope: transportation, logistics, IT goods/services

### New VAT Law (effective Jan 1, 2026)
- Amended VAT law brings compliance changes
- Businesses must review classification of supplies under new rules

## Myanmar — Internal Revenue Department (IRD)

| Field | Value |
|-------|-------|
| Tax type | **Commercial Tax** (not VAT) |
| Standard rate | 5% |
| Special rates | Up to 120% on specific goods (alcohol, tobacco, luxury items) |
| Input credit | **No input tax credit system** |
| Inclusive/Exclusive | Exclusive |
| Filing frequency | Monthly |
| E-invoicing | Not mandatory |

### Notes
- Commercial tax is a single-stage sales tax, not a multi-stage VAT
- Applied at the point of production/import
- **For Zerupt: model as simple sales tax, not VAT**
