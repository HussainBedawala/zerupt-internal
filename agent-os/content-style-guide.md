# Zerupt Content Style Guide

Single source of truth for all content creation across platforms. Claude and Hussain both reference this when creating content.

---

## Voice & Identity

**Who you are:** A young founder building the world's first agentic AI retail ERP and sharing everything along the way. You're not selling from your personal brand — you're documenting the journey so anyone can follow and learn.

**Tone:** Conversational, honest, no corporate speak. Like a smart friend who chose simple words because they want to be understood. You're a mentor by example, not by preaching.

**Language rules:**
- Write at a 14-year-old reading level. If it sounds impressive, simplify it.
- One sentence per line for rhythm and scannability.
- Use ">" for sub-points and breakdowns.
- Use "-" or "1." for lists.
- White space matters — never write walls of text.
- Say "use" not "utilize", "help" not "facilitate", "get better" not "optimize performance".
- Conversational fillers are okay sparingly: "honestly", "tbh", "look", "here's the thing".

**What you NEVER do:**
- Beg for engagement ("like if you agree", "retweet this")
- Use generic motivational fluff
- Recycle advice that's been said a thousand times
- Sound like AI-generated content soup
- Sell from personal brand — the product sells itself through the company account

## Content Formats

### Tweets / Text Posts

**Structure:**
```
HOOK (1 line, short, clear value signal)

BODY (one sentence per line, use > for sub-points)

CLOSER (1 line, insight or call to perspective)
```

**Templates:**

DEV UPDATE:
```
just shipped [feature] for zerupt

> [what it does]
> [why it matters]
> [the surprising part]

built it in [time] using [tool]
```

VALUE / HOW-TO:
```
how to [outcome] without [pain]:

1. [step]
2. [step]
3. [step]

i've been doing this for [time] and [result]
```

HOT TAKE:
```
unpopular opinion: [bold statement]

> [reason 1]
> [reason 2]

[one-line closer]
```

THREAD (weekly):
```
Tweet 1: Hook + "here's the exact process (thread)"
Tweets 2-7: One concept per tweet, ">" sub-points
Tweet 8: Recap + "follow @hussainbuildswithai"
```

**Hook formulas that trigger bookmarks:**
- "how to [X]"
- "here's how"
- "do this instead of [common mistake]"
- "the [X] mistake you're making"
- "why [X] doesn't work"
- "[number] things i learned [doing X]"

**Engagement triggers (natural, never begged):**
- Strong opinion that invites debate: "GPT writes better copy than Claude for [X], here's why"
- Open invitation: "this is my workflow, curious if anyone's tested a different approach"

### Carousels (Instagram, 1080x1350px, max 10 slides)

**Structure:**
```
Slide 1: HOOK — Bold headline (max 8 words), dark background, violet accent
Slide 2-3: THE PROBLEM — One pain point per slide, 2-3 lines max
Slide 4-6: THE INSIGHT — Numbered steps or breakdown, 1 idea per slide
Slide 7-8: THE SOLUTION — How this connects back (natural, not salesy)
Slide 9: CTA — "Follow @hussainbuildswithai" or "Join waitlist: zerupt.com"
Slide 10: PROFILE — Photo, name, "Building Zerupt"
```

**Design rules:**
- Background: Dark zinc (#18181B) or dark navy (#0C1222)
- Accent: Violet (#7C3AED) for highlights, headers, emphasis
- Secondary accent: Teal (#14B8A6) for contrast elements sparingly
- Text: White (#FAFAFA) primary, zinc-400 (#A1A1AA) secondary
- Font: IBM Plex Sans (headings bold, body regular)
- One idea per slide. If it needs two ideas, it needs two slides.
- Include real screenshots/code when possible — proof over polish

**Carousel types to test:**
1. Story-driven: "I built [X] in [time]. Here's exactly how." (building zerupt pillar)
2. Listicle: "[N] things about [topic]" (educational)
3. Before/after: "How retailers manage [X] now vs with AI" (retail pain)
4. Breakdown: "The architecture behind [feature]" (technical)
5. Controversial: "[Hot take]. Here's why I'm right." (engagement driver)

### Reels / Video (30-60 sec)

**Structure:**
```
HOOK (0-3s): "I just [surprising thing] in [surprising time]"
CONTENT (15-45s): Screen recording or talking head, 3 key points max
CTA (3-5s): "Follow for daily builds" or "Link in bio"
```

**Video types:**
1. **Screen recording + voiceover:** Show actual code/terminal/UI being built. Raw > polished.
2. **Talking head:** Direct to camera, explain a concept or share a hot take.
3. **Hybrid:** Start talking head for hook, cut to screen recording for proof, back to face for CTA.

**Production:**
- Record during dev with QuickTime (Cmd+Shift+5)
- Trim in CapCut (free)
- Auto-captions via CapCut
- Raw and authentic always beats overproduced
- Vertical (9:16) for IG Reels

### Stories (Instagram)

- Daily dev progress updates (screenshot of terminal, UI, Linear board)
- Quick polls: "What should I build next?" / "Should I do X or Y?"
- Behind-the-scenes: desk setup, coffee, late night coding
- Repurpose best tweets as story screenshots

## Content-from-Dev Pipeline

Dev work IS content. You don't create content separately — you extract it from what you ship.

1. Finish a dev task in Linear (Development team)
2. If content-worthy, create a linked issue in Linear (Marketing team) with label `dev-triggered`
3. Claude generates drafts based on what was shipped
4. Hussain reviews, edits voice/authenticity, posts manually

**What's content-worthy:**
- Shipped a visible feature (UI, architecture decision, integration)
- Hit a milestone (phase complete, first user, waitlist number)
- Solved an interesting technical problem
- Made a non-obvious decision (chose X over Y, and here's why)
- Something failed and you learned from it

**What's NOT content-worthy:**
- Routine bug fixes
- Config changes
- Dependency updates

## Key Principles

1. **Dev work IS content.** Extract, don't create from scratch.
2. **Consistency > quality.** A good-enough post daily beats a perfect post weekly.
3. **30-45 min/day max.** If content takes longer, the system is broken.
4. **Personal account leads.** People follow people. @hussainbuildswithai drives awareness, @zerupt.erp converts.
5. **Automate generation, not posting.** Claude drafts, Hussain reviews and posts manually.
6. **Measure and adjust weekly.** Sunday analytics. Double down on what works.
7. **Trial and error on formats.** Test carousel types, reel styles, posting times. Let data decide.
