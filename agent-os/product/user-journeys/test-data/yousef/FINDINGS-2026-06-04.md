### NEW-21 — Imported products have no tax group → unsellable at POS (FIXED)
**Severity:** CRITICAL (blocks the core migrate-then-sell promise)
**Found:** L7 POS sale — adding any imported item returned 422 "Item has no tax group configured and cannot be sold at POS".
**Root cause:** `ImportApplyService` never set `items.tax_group_id`; provisioning creates a default "No Tax" group but imports ignored it.
**Fix:** `loadTaxContext()` loads active tax groups (name→id + default); `applyProductChunk` resolves the row's `taxGroup` cell, falling back to the tenant default. Spec updated (20/20 green). Live tenant backfilled: 2898 items → "No Tax".
**Residual:** per-row `applyProduct` path (currently unreachable for products) still omits taxGroupId; validation step could warn when a file has no tax column. → **FIXED 2026-06-05** (per-row path now threads taxCtx).
