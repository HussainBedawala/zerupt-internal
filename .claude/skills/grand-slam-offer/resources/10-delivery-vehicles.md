# Phase 6: Delivery Vehicles & The Trim/Stack

> Source: $100M Offers, Chapter 12 — "Enhancing the Offer: Trim & Stack"

## Core Principle

Now that you have a list of problems and solutions, you need to decide HOW to deliver each solution. The delivery vehicle determines both the **perceived value** and the **cost to deliver.**

## The Delivery Cube

Every solution can be delivered through a combination of 3 dimensions:

### Dimension 1: Level of Personal Attention
| Level | Description | Perceived Value | Cost to Deliver |
|-------|-------------|-----------------|-----------------|
| **1-on-1** | Personalized, individual | Highest | Highest |
| **Small Group** | Semi-personalized, cohort | High | Medium |
| **1-to-Many** | Courses, software, content | Medium | Low |
| **DIY** | Self-serve, documentation | Lowest | Lowest |

### Dimension 2: Effort Required from Customer
| Level | Description | Perceived Value |
|-------|-------------|-----------------|
| **Done-For-You (DFY)** | You do everything | Highest |
| **Done-With-You (DWY)** | You guide, they execute | High |
| **Do-It-Yourself (DIY)** | They figure it out alone | Lowest |

### Dimension 3: Format / Medium
- Live calls / meetings
- Recorded video / course
- Written guides / docs
- Software / automation
- Templates / frameworks
- Community / forum
- Chat / messaging support
- In-person events

## Mapping Solutions to Vehicles

For each solution from Phase 5, choose the delivery vehicle that:
1. **Maximizes perceived value** for the customer
2. **Minimizes cost** for you to deliver
3. **Aligns with your business model** (scalable for SaaS)

The sweet spot: **high perceived value + low delivery cost.**

## The Trim & Stack Process

### TRIM: Remove Low-Value, High-Cost Items
- If it costs a lot to deliver but doesn't move the value needle much → CUT IT
- If nobody would miss it → CUT IT
- If it's "nice to have" but not solving a real problem → CUT IT

### STACK: Keep High-Value, Low-Cost Items
- Things that are cheap/free to deliver but increase perceived value → ADD MORE
- Digital assets (templates, guides, tools) = high perceived value, near-zero marginal cost
- Access to community/group = high perceived value, low cost
- Bonuses that solve adjacent problems = massive perceived value

## For SaaS Specifically

SaaS has a natural advantage — software IS the delivery vehicle for most solutions:
- **Core product** = the 1-to-many, DIY delivery vehicle
- **Onboarding** = DWY or DFY layer on top
- **Templates/presets** = high value, zero marginal cost
- **Training** = recorded once, delivered infinitely
- **Community** = customers help each other
- **Success manager** = 1-on-1 layer for premium tiers

## Interview Goal

By the end of this phase, you should have:
- Each solution mapped to a specific delivery vehicle
- A clear sense of which items are high-value/low-cost (keep)
- Items identified for trimming (high-cost/low-value)
- The beginning of the offer stack
