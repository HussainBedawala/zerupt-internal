## UAE — Federal Tax Authority (FTA)

| Field | Value |
|-------|-------|
| Tax type | VAT |
| Standard rate | 5% |
| Zero-rated | Exports, international transport, first supply of residential property, healthcare, education |
| Exempt | Bare land, local passenger transport, certain financial services |
| Inclusive/Exclusive | Exclusive (added on top) |
| Registration threshold | AED 375,000 (mandatory), AED 187,500 (voluntary) |
| Filing frequency | Quarterly (default), monthly (for large businesses) |
| E-invoicing | Planned — no mandatory e-invoicing yet as of 2026 |
| Reverse charge | Simplified Jan 2026 — no self-invoice required; retain supporting docs instead |

### 2026 Changes (effective Jan 1, 2026)
- **5-year refund deadline**: Excess recoverable VAT lapses if not used/refunded within 5 years
- **RCM simplification**: No self-invoice needed for imports under reverse charge
- **Enhanced FTA powers**: Can deny input VAT recovery if supply connected to tax evasion
- **Transitional relief**: Fresh 1-year window for credits that expired before Jan 2026

## Saudi Arabia — ZATCA

| Field | Value |
|-------|-------|
| Tax type | VAT |
| Standard rate | 15% |
| Zero-rated | Exports, international transport, medicines, medical equipment |
| Exempt | Certain financial services, residential property rental |
| Inclusive/Exclusive | Exclusive |
| Registration threshold | SAR 375,000 (mandatory), SAR 187,500 (voluntary) |
| Filing frequency | Monthly (turnover > SAR 40M), quarterly (others) |
| E-invoicing | **ZATCA Fatoora — mandatory, phased rollout** |
| Reverse charge | Yes — imports of services, certain domestic supplies |

### E-Invoicing (Fatoora Platform) — 2026 Waves
| Wave | Deadline | Turnover threshold |
|------|----------|-------------------|
| Wave 23 | Mar 31, 2026 | Revenue > SAR 750,000 (in 2022/2023/2024) |
| Wave 24 | Jun 30, 2026 | Revenue > SAR 375,000 (in 2022/2023/2024) |

- Phase 2 (Integration): Real-time invoice reporting and clearance via Fatoora
- B2B invoices require clearance before issuance to buyer
- B2C invoices require reporting within 24 hours

## Bahrain — National Bureau for Revenue (NBR)

| Field | Value |
|-------|-------|
| Tax type | VAT |
| Standard rate | 10% |
| Zero-rated | Exports, basic food items, international transport |
| Exempt | Certain financial services, bare land, local transport |
